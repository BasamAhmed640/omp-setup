# Restore the independent review-and-repair flow for Learn, Exam and Tutor

## Context

The product must work like this: the authoring agent writes the lesson / exam form / tutor explanation, an **independent review agent** inspects it against the source PDF, findings come back as concrete fix requests, the author repairs or answers them, and only then does the target commit. That flow already exists in this repository — commit `5f24885` (v0.6.0) shipped it for all three modes — and commit `5d959e2` (v0.7.0) deleted only its **production callers**: `review-runtime.ts`, `review-layer.ts`, `learn-review.ts`, the receipt schema (`section.learnQuality.reviews`, `exam.review`, `tutor.review`), the gates (`reviewGateIssues`, `learnReviewIssues`), the renderers that display receipts, and the widget methods `loadingReview` / `loadingReviewOutcome` are all still present and passing their own verifiers. What is gone is: `withReview`, `saveReviewCheckpoints`, `reviewQuestion`, the Learn `lessonComplete` review pass, the Tutor explanation pass, the Exam form pass, the question-review hook, and the review clauses in the mode instructions.

No wall-clock limit is added or restored, and v0.6.0's 15-minute stall stop (`PROGRESS_STALL_MS` + the coordinator watchdog) stays deleted. The loop ends by construction, not by a clock: approval is hash-bound per role, a crew pass runs **at most once per activation** (a resubmission after findings only checks the recorded `findingResponses` — it never re-runs the crew), finished packet checks are persisted as checkpoints and reused so no inspection is repeated, and the existing caps (4 delivery-gap attempts, 8 consecutive rejections, 250 actions) stop a pathological run with the draft kept. The only clock left in the system is inside `review-runtime.ts`, where a single isolated reviewer run is bounded (`DEFAULT_REVIEWER_LIMITS`, `REVIEW_STALL_MS`) because a provider that stops streaming cannot be caught by any counter; those receipts are `timeout` failures, and checkpoints make the retry resume instead of restart.
